## Run natively (proposal for `AGENTS.md`; the lead owns that file)

```sh
# worktree root; once
pnpm install --frozen-lockfile && task packages
git checkout -- packages/omniviewdev-vite-plugin/shims/_omniviewdev__runtime__models.mjs
# cluster, fixture, plugin at the CI pin, kubeconfig for the plugin's HOME: plan appendix A.2 to A.4 (docs/ui-next/slices/1a-pods-list.md)
#   kind create cluster --name n12a-native --kubeconfig /tmp/n12a/kubeconfig ; fixture ; plugin into $HOME/.omniview-feature-ui-next/plugins/kubernetes (bin/ + plugin.yaml)
export HOME_N=/tmp/n12a/native-home        # isolated state root; never ~/.omniview
# the native window cannot take ?screen=pods (finding F1): until that is solved, edit ui-next/main.tsx locally to `params.get('screen') ?? 'pods'`; do not commit it
OMNIVIEW_UI=next task build OUTPUT=/tmp/n12a/build/Omniview      # frontend (next flavour) then Go, -tags production, 16 s
mkdir -p /tmp/n12a/app/Omniview-N12a.app/Contents/{MacOS,Resources}
cp build/darwin/icons.icns /tmp/n12a/app/Omniview-N12a.app/Contents/Resources/ && cp build/darwin/Info.plist /tmp/n12a/app/Omniview-N12a.app/Contents/
cp /tmp/n12a/build/Omniview /tmp/n12a/app/Omniview-N12a.app/Contents/MacOS/
#   edit CFBundleIdentifier in that Info.plist to dev.omniview.n12a.native-ui, then:
codesign --force --deep --sign - /tmp/n12a/app/Omniview-N12a.app
(HOME=$HOME_N OMNIVIEW_CHANNEL=feature-ui-next nohup /tmp/n12a/app/Omniview-N12a.app/Contents/MacOS/Omniview >/tmp/n12a/run.out 2>/tmp/n12a/run.err & echo $! >/tmp/n12a/run.pid)
# observe: winlist <pid> for the window id, then screencapture -x -o -l <id> out.png
# stop: kill $(cat /tmp/n12a/run.pid)   (its plugin child exits with it); kind delete cluster --name n12a-native --kubeconfig /tmp/n12a/kubeconfig; git checkout the local main.tsx edit
```

## Dev tools (what the owner saw at the bottom right of the window)

The green block at the bottom right was **my own test overlay, not a product feature**. It is not React or Query devtools, not an existing host dev overlay and not a performance HUD. Source: `ui-next/n12a-debug.ts` (a copy: `docs/ui-next/status/N12a/n12a-debug.ts.txt`). It was injected by one local line, `import './n12a-debug'`, at the top of `ui-next/main.tsx` in the build I ran for the Tab, console and font checks (not in the first, clean screenshots). It was never committed and is not in any build of the repo: `git status` is clean, and `OMNIVIEW_UI=next` or stable builds do not contain it. It prints: `console.error`/`warn`, `window.onerror`, unhandled rejections, every `focusin` target (tag, role, aria-label, text), the `document.fonts` load status, the user agent, `devicePixelRatio` and the viewport. It measures no interaction timing and runs no aria checks. On: add the import and rebuild. Off: remove it.
