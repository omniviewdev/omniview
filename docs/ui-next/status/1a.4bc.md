## Decisions

- **Chip** (`Chip.tsx`, 3.5 KB source): three modes, one at a time (a union type): static text (a `span`, 18 px), a toggle (`onClick`, optional `pressed`: a native `button`, 28 px, `aria-pressed`), removable (`onRemove`: static text and a 24 px Remove button named `Remove <text>`, the chip itself is never a button). Tones `success | warning | error | info | muted`, a count (`<b>`, plain text colour; zero is a value). The prop is `pressed`, as the spec (14 V3, 15 4.3) and `aria-pressed`; the lead's note says "selected": `QuickFilters` uses `selected` for the chosen filter. Not built, no screen needs them: disabled, link, type tag, `mono`, `strike`, `color`/swatch, `label`, `tip`. The mock's cascade is kept: a tone paints over the control edge of a toggle, a pressed chip paints over its tone; the hover is a `background-image` gradient so the tone fill stays under it.
- **RovingGroup**: DOM-driven as the mock (it acts on the buttons and links it holds, so any part is a member): one tab stop (the item that last had the focus, else pressed / current / selected, else checked, else the first), arrows of its axis without wrap, Home and End (Control allowed with them only), Alt, Meta, Shift chords ignored, `aria-disabled` items stay reachable, natively disabled or hidden ones are skipped, items inside a menu, radio group or popover belong to those, the nearest group wins. The tab stop is normalised after every render and by a `MutationObserver` for changes a child makes on its own; an unchanged update writes nothing (tested). Kinds `row` and `column`; layout props `gap`, `wrap`, `align`. **The mock has no type-ahead, so none is built.** Not built, no 1a screen needs them: the mock's `list` and `grid` kinds (`grid` is the one algorithm not covered), RTL.
- **QuickFilters**: All is implicit (`total`, then `filters`), `selected: string | null` (null is All; an id that names no filter is All too, so exactly one chip is pressed), `onSelect(id | null)` also for the already selected chip (whether that clears the filter is the caller's rule, as in the mock's page), controlled. The tone of a filter shows only while its count is above zero or known (the mock's page does this; the kit does it in the strip). The counts are the caller's and are printed as given; the examples' counts add up (89 = 80 + 4 + 3 + 2) and a test asserts it from the rendered chips. The strip is a `RovingGroup` (row, gap 8, wrap, centred): 1 + 3 elements per chip.
- **Status**: the closed seven-role table (`roles.ts`: healthy `status-success`, running `play`, progress `loader-circle`, attention `status-warning`, error `status-error`, stopped `circle-minus`, info `status-info`; no glyph shared). A span, the glyph, the word as a bare text node: 3 elements, 4 for the four two-paint glyphs (the plan's cell budget of 4 counted a CSS-mask glyph and the `td`; with the inline svg the Status cell is `td` + 3 or 4: flag for the table owner). `queued` (progress only, by type) draws the clock of SR1; **E8 stays open for the lead**: without `queued` the glyph is the mock's loader, so the caller chooses which words are queued. A bare boolean (Yes, No, True, False) prints as plain words with no element (SR2). Not built: `busy`, `symbol`, `header` (no 1a screen draws them).
- **MissingValue**: the muted em dash, `role="img"` with the accessible name `name` (default "Not applicable") and, when there is a reason, `name: reason`; one element; the reason is not drawn (the tip is the shared host's, 1a.4d). An empty name or reason is taken for none.
- **KindTile**: `icon` (any glyph of the registry), `tone` (`neutral` = the icon role, or one of the seven brand hues of the token scale), `size` 20 or 16 (the glyph is 16 px in both); decorative (`aria-hidden`); 3 elements. The kit knows no kind: the mapping from a kind to a glyph and a tone is the caller's data.
- **MiddleEllipsis**: CSS only, as the mock's host (`.pmid`): the head gives way with an ellipsis, the tail stays whole; a name of 13 characters or more is split (a shorter one is cut at its end), the tail is the caller's `tail` or a third of the name from 6 to 12, never the whole name; characters are code points. 1 element (short) or 3. **The signal for the tip host (agreed with Slice1aTooltipFonts)**: the root is the clipping box (`overflow` hidden) and carries `data-ov-clip` (and, split, `data-ov-full`, the whole name, which a hidden `::after` copy turns into the root's scroll width); the host tips the full name only while `scrollWidth > clientWidth + 1`, measured at hover or focus time, nearest `[data-ov-tip], [data-ov-clip]` owner wins, no `aria-describedby`. No `isCut` is exported: the host keeps its private copy of the one-line rule.
- **Examples**: every part ships `<Part>.examples.tsx` (Chip 21, RovingGroup 5, QuickFilters 4, Status 10, MissingValue 3, KindTile 5, MiddleEllipsis 7 examples); the parts page renders them through the registry with no edit.

## Findings for the lead and the errata pass (N10)

- The mock's `.pclip` (a name of 12 characters or fewer) has no `white-space: nowrap`: in a bare box it wraps to two lines (32 px); only a table cell supplies the nowrap. The kit's plain variant is nowrap itself.
- The mock draws a static chip in two layouts: an inline block when it holds text only, a row of flex items when it has a count.
- The mock's quick filter strip does not mute an empty state itself: the Pods page passes `tone: 'muted'` for a zero count. The kit's strip does it.
- In the mock, Alt+ArrowRight in the strip is prevented but moves nothing (Shift, Meta, Control with an arrow are left alone); Tab from the page header's Refresh button lands on the overflow menu button, not on the strip.
- The mock's real Pods route reads counts 89, 78, 0, 2, 9 (All, Running, Pending, Failed, Completed): they do not add up (the statuses `Terminating` and `Unknown` have no filter), so "counts add up" holds for the examples and for the strip's data contract only when the caller's filters partition the list.
- Playwright's macOS WebKit does not Tab to buttons (Alt+Tab does), as in 1a.4a: the native pass must check Tab to a chip.
