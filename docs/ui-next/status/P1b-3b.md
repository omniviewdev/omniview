## What was built (plugin, `ui/src/pod/`)

- **`logs/target.ts`**: the descriptor (`LogTargetV1`): `id` `pod/<connection>/<namespace>/<name>` (each part URI-encoded: an EKS connection holds slashes), `title` the Pod's name, `scope` the connection as the scope lane names it (the lane prints `Connection.id`), `resource` `Pod <name>` + `Pod` + the Pod glyph + the Pod page's route AS THE PAGE WAS OPENED (no connection in it when the page's route had none, so the card's link finds the open tab); `open` is `openLogStream` for the Pod's own record (body, reference and route as the host holds them), `target: ''`, follow, tail 1,000, previous off, `filter_labels: container`. Its result goes to the host as it is.
- **`logs/command.ts`, `availability.ts`**: the header's primary command calls `ctx.panel.logs.open`. Disabled with a reason when the host gave no `ctx.panel` ("This version of Omniview cannot show logs here.") and when no container (regular, init or debug) ever ran: running, terminated, or only a `lastState.terminated` ("No container of this Pod has started, so it has no logs yet."). Decided from the record the page holds (live).
- **`logs/card.ts`** (`contributionV1.panel.sessions.logs.card`): Connection, Namespace, Container (the mock's rows). `usePod` hands over the record; the stub reason names Shell and Delete only now.

## What the first real stream showed, against the fixture-fed behaviour

- **Wire:** one line a frame when live (10 a second), the opening backlog in batches; a line is `{ session_id, source_id: "<pod>/<container>", labels: { container, namespace, node, pod }, timestamp: RFC 3339 Nano UTC, content, origin: 0, level: 0 }`. `level` is 0 and `origin` 0 on every line of every session.
- **Level detection** is the view's alone, and works on the text: `INFO starting`, `WARN config file not found…`, `ERROR fatal…` drew INFO, WARN, ERROR; a counter line has no level (the cell is `—`).
- **Timestamps:** the kubelet's, shown in local time to the millisecond; they equal kubectl's. Lines written together share a millisecond (the burst).
- **`active_sources`:** `[]` (an empty array) in every `CreateSession` answer the proof recorded (`counter`, `burst`, `crashloop`, `duo`, `withinit`), never `null`; the sources are announced afterwards by events (`Started streaming from <pod>/<container>`, `All sources connected`, `Log session ended.`). A later `ListSessions` lists them, with `plugin_id` and `connection_id` empty.
- **Several sources:** the SDK makes one source per container (init, regular, debug); the lines arrive in arrival order, not clock order (110 of `duo`'s 2,225 rows have a clock earlier than the row above), and **the row has no source**: the view's cells are time, level and text.
- **The strip's rate** counts the opening backlog as the first second (`339.7 lines/s`, then `10.0`).
- **A page that goes away without closing its tabs leaves the SDK sessions running** (a first page's counter session kept sending frames to the next page; the host emits to every window, P1b1-13). Closing the TAB closes the session (check 5). A host restart brings the panel's sessions back ended (`The session ended when the app restarted.`, S3a): as designed.

## Decisions made here (for the lead to keep or reverse)

1. **One session per Pod, following ALL its containers** (`target: ''`): the stream supports several sources (checks 8). The spec's "(the source shown as the mock does)" cannot be met: the host's view shows no source per line (finding 2), so on a Pod with a sidecar the lines interleave with no label. The alternative is one constant: `target` the default container (the `kubectl.kubernetes.io/default-container` annotation, then the first regular container), which is what `kubectl logs <pod>` prints and what the mock opens; its availability rule would then ask whether THAT container ran. I kept the lead's first choice; say if you want the other until P1b-4's Container control.
2. **The card's `facts` are the plugin's** (Connection, Namespace, Container) and so replace the host's `Source(s)` and `Paused` (the contract: facts replace whole). `Paused` cannot show today (no control), and the sources are not in what the card function is given (finding 3).
3. **`scope` is the connection as the lane says it.** The mock puts the namespace in the tab's tail; the host's rule is the connection. Two same-named Pods in two namespaces of one connection are told apart by the ordinal and the card.
4. The command keeps its place for a crash-looping, finished, initializing or terminating Pod (a log exists); only a Pod no container of which ever ran is disabled.

## Open

- **Log row times are LOCAL while the detail page shows UTC** (the lead saw it: the screenshot has rows at `21:22` and the page at `Created 03:14 UTC`, a Pod 8 minutes old, on a machine at UTC-6). Both are what the mock draws, so no fix here; what the mock does for each:
  - **The log rows: the viewer's local clock, UTC as a display option.** `shell-panel.js:129-132` `clock(ms, { utc = false, millis = true })` reads `getHours()` and the rest unless `utc`; `:1708` makes every row with two time spans, `plog__t--local` (`clock(l.t)`) and `plog__t--utc` (`clock(l.t, { utc: true })` and a `Z`); `shell-panel.css:107-110` hides the UTC one unless the list is `data-ts='utc'` (then the local one is hidden) and hides both for `data-ts='off'`; `:2450` builds the list (`plog__scroll`) with its `data-ts`; the line inspector shows both, `:2099` (`Time (local)`, `Time (UTC)`). The kit's `formatClock` takes the same `{ utc }` (`packages/kit/src/log/time.ts:8`); the host's Logs view has no display option for it yet (the mock's is in Display options: P1b-4).
  - **The detail page: every absolute time in UTC, to the minute.** `k8s-resource-definitions.js:154` `stampOf` (`toISOString().slice(0, 16)` and ` UTC`) is what an age's long form prints (`:217`: `<stamp> · <ago>`, the tip of the compact `8m`) and what the Started and exit tips print (`:1463`, `:1474`); a `timestamp` field such as the metadata's `Created` (`:910`) is the compact relative label with the raw RFC 3339 text as its tip (`k8s-resources.js:234-237` `compactTime`, `:345`). The plugin's `Created` row is `stampOf` (`ui/src/pod/overview/model.ts:17` `utcStamp`, "the mock's `stampOf`"), so the page prints in UTC what the mock keeps in a tip.
