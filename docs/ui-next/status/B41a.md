## How likely (the agent and the user)

- **What is certain:** a data race, found by `-race` on a stand-in, and by reading the code path above for the real objects: the comparison reads `pluginState.provider` while plugin stop writes it. Nothing synchronises the two.
- **What is not shown:** a crash. For the real objects DeepEqual returns at the first unequal leaf: it walks `provider` and `backend` (two distinct provider objects) and then `version` and `cancel` (two non-nil funcs: "not equal"), so the maps of `pluginState` that are written under `pluginsMu` (`sourceEpoch`, `catalogBindings`, ...) come after the return. A fatal "concurrent map read and map write" needs a map inside the walked `provider` or `backend` that is written at that moment; I did not read every provider implementation. I did not reproduce it with a real controller (an `Observation` cannot be built outside the `resource` package, and the test is in the stand-in form: a provider with a map and its own lock).
- **Who:** the host process, when an MCP tools refresh (or a bound agent call, `allowedLocked`) coincides with a plugin stop or restart. The agent sees nothing but a failed or cancelled tool call at worst; the user sees a host crash only if the fatal map case above holds. Rare: it needs a generation change between two catalogs.
- **The agent boundary** (`status/E0-1.md`): the relay returns a fixed string for every failure (`server.go:988-1002`, `agent_error_boundary_test.go`). This change touches only the comparison, no error text path; `TestPluginErrorTextNeverReachesAnAgent` and `TestErrorResultCarriesFixedTextOnly` pass unchanged.

1. `Observation.Same` is a new exported method in the credential-broker track's package (new file, no existing file edited; allowed by the lead's message). They may want to own it.
2. `finite_catalog.go:71`: the register-the-key idiom has no test.
