## How versions and staleness work

- One home per version: Node `.tool-versions` (`nodejs`), pnpm `package.json` `packageManager`, Playwright `pnpm-lock.yaml` (the one version `playwright`, `playwright-core` and `@playwright/test` resolve to; two versions are `playwright-ambiguous`). Go: `go.mod` is a floor (same series, patch at or above), the Dockerfile pins one exact patch (1.27.3, the patch five workflows pin). kind, kubectl, golangci-lint: the Dockerfile's, checked against the copies the Pods workflow and PR Checks still carry (`tool-mirror-mismatch`).
- The lock holds the hash of the inputs (Dockerfile bytes, Node, pnpm, Playwright, Go floor), tag, digest and the manifest. `check` fails on `inputs-behind`, `playwright-mismatch`, `node-mismatch`, `pnpm-mismatch`, `go-mismatch`, `digest-split`, `digest-mismatch`, `lock-missing`, `lock-invalid`, `manifest-incomplete`; it warns on `mutable-pin` (5 today: `pr.yml`, `pr-checks.yml` x2, `e2e-runner.yml`, `desktop-build.yml`) and `lock-old` (older than 21 days). B4 passes `--require-digest-pins` to make `mutable-pin` an error.
- Rebuild: weekly (Monday 05:17 UTC) always; on a push to main when the lock is behind; on a pull request when the inputs moved or an image file changed (build and smoke, never a push); `workflow_dispatch` with `publish: true` from any ref (`gh workflow run ci-image.yml --ref <branch> -f publish=true`, then `gh run download <run> -n image-lock && git apply image-lock.patch`). The workflow runs on `pnpm-lock.yaml`, `package.json`, `go.mod`, `.tool-versions` and any workflow change; the guard decides whether to build, because a path filter cannot see "the Playwright line changed".
- Tags `ubuntu24-<yyyymmdd>-<sha7>`, never overwritten. `ubuntu24-v1`, which the five consumers still pull, **is no longer rebuilt**: it stays what the last Monday build made it until B4 moves them to the digest.
- No BuildKit layer cache: 2 to 3 GB of it would compete with the browser and Go caches in a repository cache that is already over its limit (11.2 GB of 10, 34 caches).
