## What a definition could NOT express and needed code for

1. **A Secret's rule "never read a value".** Every other kind reads a record through `bodyOf`, which turns the whole `Value` tree into JSON. A Secret's row model walks the tree to `metadata`'s four members, `type` and the key names of `data`, and touches nothing a key holds, an annotation either (`last-applied-configuration` can hold the values whole). A definition cannot say "read only these members"; a decoder written for the kind does, and a test hands it a record whose values throw when read.
2. **Cells derived from a map's entries and values.** A ConfigMap's Key names (sorted union of `data` and `binaryData`) and Size (the UTF-8 bytes of the text, the bytes a base64 value decodes to) are arithmetic over the entries, in the kind's decoder.
3. **A text with a rest.** `a, b, c +2` (key names), `10.0.0.1, 10.0.0.2 +1` (addresses) and `v1.31.4` for `v1.31.4-eks-aeac579` need the whole behind the cell: the closed vocabulary's `text` cell gained a `tip`, and `display.ts` a `namesCell` and a `textCell`.
4. **A line under the name that is not a namespace.** A Node says its address there (the mock's `identity: 'internalIP'`), a Namespace says nothing. The identity cell names the line in its test id (`node-address`; the namespace stays `*-namespace`, which the host's cluster check reads), by an optional `line` of the definition.
5. **A word that is two facts.** A Node: kubectl's `Ready,SchedulingDisabled` is one word in K61.1 (`Scheduling disabled`, a stopped state) for a Node that is Ready, and a Node that is not never has its trouble hidden by a cordon. A CronJob: the word is a boolean in the user's words. A ReplicaSet: the K2a rule without a paused rollout and a current template, and `Ready` for `Available`. Each is a function a definition names.
6. **No strip.** Five kinds have no `quick` in the mock. The contract's `quickFilters` is optional; the definition says `[]` and `listDefinition` hands the host no strip (a strip with only All filters nothing).
7. **Not expressed at all, because the contract has no place for it**, as in K2a: facets (Service Type, Secret Type, Ingress Class), the wide set (ReplicaSet Images, CronJob Suspend and Time zone, Service External IP, Ingress TLS hosts, Namespace Labels, Node Memory), the Columns chooser, sort state, selection and `Create`, and a count on a sidebar entry. **Node CPU** is a default column of K60.3 and a usage: no metrics read is in `ui/v1`, so it is not drawn and no zero stands for it.
