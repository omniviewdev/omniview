## Boundary and ownership

P07 owns catalog, schema normalization, value admission and the CEL adapter; P12 owns acquisition interests and revision-consistent snapshots; P13 owns compilation, planner, finite evaluation and host window semantics; P14 owns authorization at its lease boundary, lease sharing, result generations, event wire, and delivery. P15 is a passive observer. No spike data structure, independent schema model, custom evaluator, client planner, or old Find fallback is introduced.

P13 uses Go module `cel.dev/cel-go v0.33.1` with `replace cel.dev/cel-go => github.com/omniviewdev/cel-go v0.33.2-0.20261028172556-d7bb038d8c7b`. P01's immutable profile manifest, optimization and cross-type numeric settings, profile implementation revision and finite policy apply. The fork does not authorize new operators or public value tags. Replacing it requires P01 profile/conformance review. P01 historical numeric hold is superseded only by its accepted fork-first receipt, not by this specification.

## Go consumer interface

These are host-internal APIs, not Wails or provider wire DTOs. Named value types below are P13-owned immutable host values; P01 `QuerySpec`, `QueryScope`, `BoundValue`, resource identity and C02 `AppError` retain their existing canonical definitions. Implementations must use their actual package names rather than introducing parallel domain aliases. Signatures below identify ownership and behavior; no stub implementation may land to satisfy them.

P13 owns the strict request DTOs in `backend/pkg/plugin/resource/query`; P15 owns their exact TypeScript mirror in `packages/omniviewdev-runtime/src/resource/v2/query.ts`. They consume P45 `resourcev2.Value`, `ResourceReference`, `AccessRoute`, and `QueryScope`, not competing aliases. The semantic version, discriminants, path segments, Builder grammar and admission rules are exactly P01 §§2 and 5; unknown/duplicate JSON members and invalid variants reject before dispatch.

```go
type QuerySpec struct {
    Version string `json:"version"`
    Targets []Target `json:"targets"`
    Predicate Predicate `json:"predicate"`
    Declarations map[string]BindingType `json:"declarations"`
    Bindings map[string]resourcev2.Value `json:"bindings"`
    Text *TextConstraint `json:"text,omitempty"`
    Projection []Projection `json:"projection"`
    Order []OrderTerm `json:"order"`
    Delivery Delivery `json:"delivery"`
}
type Target struct {
    TargetID string `json:"targetId"`
    Provider string `json:"provider"`
    Authority string `json:"authority"`
    Type string `json:"type"`
    AccessRoute resourcev2.AccessRoute `json:"accessRoute"`
    Representation RepresentationSelector `json:"representation"`
    Scope resourcev2.QueryScope `json:"scope"`
}
type RepresentationSelector struct { ID string `json:"id"`; Revision string `json:"revision"` }
type Predicate struct {
    Language string `json:"language"`
    Profile string `json:"profile,omitempty"`
    Source string `json:"source,omitempty"`
    Version string `json:"version,omitempty"`
    Document json.RawMessage `json:"document,omitempty"` // strict P01 Builder v1 grammar
}
type BindingType struct {
    Kind string `json:"kind"`
    Element *BindingType `json:"element,omitempty"`
    Value *BindingType `json:"value,omitempty"`
}
type PathSegment struct { Kind string `json:"kind"`; Name *string `json:"name,omitempty"`; Index *uint32 `json:"index,omitempty"` }
type DocumentFieldPath []PathSegment
type TextConstraint struct { Term string `json:"term"`; Fields []DocumentFieldPath `json:"fields"`; Match string `json:"match"`; Case string `json:"case"`; Combine string `json:"combine"` }
type Projection struct { ID string `json:"id"`; Path DocumentFieldPath `json:"path"` }
type OrderTerm struct { Path DocumentFieldPath `json:"path"`; Direction string `json:"direction"`; Missing string `json:"missing"`; Null string `json:"null"` }
type Delivery struct { Mode string `json:"mode"`; PageSize uint32 `json:"pageSize"`; After *string `json:"after,omitempty"`; AllowPartial *bool `json:"allowPartial,omitempty"` }
```

`Predicate` is exactly `{language:"cel",profile,source}` or `{language:"builder",version,document}`; validate the Builder raw object against the complete P01 §5 grammar, never pass opaque unchecked data to CEL. `BindingType` is scalar `{kind:"bool"|"string"|"int64"|"uint64"|"double"|"timestamp"}`, list `{kind:"list",element}`, or map/nullable `{kind:"map"|"nullable",value}` with the other fields forbidden. A path segment is exactly member `{kind:"member",name}` or index `{kind:"index",index}`, with the other field forbidden. Text is only substring/sensitive/any. The host expands the request's representation selector to C04's full `resourcev2.RepresentationBinding` using the authorized catalog; ID or revision mismatch yields `RESET_REQUIRED`. Clients never echo full schema bytes. Bound values use P45 tagged JSON, including decimal int64/uint64 strings.

The TypeScript mirror has the same JSON field names and required/optional status: `QuerySpec={version:string;targets:Target[];predicate:Predicate;declarations:Record<string,BindingType>;bindings:Record<string,Value>;text?:TextConstraint;projection:Projection[];order:OrderTerm[];delivery:Delivery}`; `Target={targetId:string;provider:string;authority:string;type:string;accessRoute:AccessRoute;representation:RepresentationSelector;scope:QueryScope}`; `RepresentationSelector={id:string;revision:string}`. `Predicate`, `BindingType` and path segments are the discriminated unions just specified; `DocumentFieldPath` is `PathSegment[]`; text, projection, order and delivery mirror the Go JSON tags with optional `after` and `allowPartial`. `Value`, `AccessRoute` and `QueryScope` are the existing P45 runtime domain types. Integers within `Value` remain strings, never JavaScript numbers. No compiler AST, provider cursor or host authorization token is a persisted request DTO.

`delivery.pageSize` must be at least 1 and no greater than the admitted window bound (C08 ceiling 512); zero or over-bound returns `INVALID_REQUEST`. Strict decoding rejects duplicate members, including nested declarations, bindings and projection objects; Go `encoding/json` last-wins is not sufficient. P15's `query.ts` is the only exported TypeScript `QuerySpec`; C08's typed Wails adapter consumes it, not any independently generated Wails model.

```go
// package query
// QuerySpec is the canonical P01 request; invocation.Principal is host-issued.
type Compiler interface {
    Compile(ctx context.Context, spec QuerySpec, principal invocation.Principal) (*CompiledQuery, error)
}
type Acquisition struct {
    Mode string // snapshot | snapshotAndUpdates
    Native *NativeAcquisition // nil means enumerate
}
type NativeAcquisition struct { Language string; Query resourcev2.Value }
type SourceBinder interface {
    Bind(ctx context.Context, principal invocation.Principal, target resourcev2.ReadTarget, acquisition Acquisition) (readmodel.Binding, error)
}
type CatalogSource interface {
    Snapshot(ctx context.Context, principal invocation.Principal, target resourcev2.ReadTarget) (*resourcecatalog.Snapshot, error)
}
func NewExecutor(manager readmodel.Manager, binder SourceBinder, catalog CatalogSource) Executor
type Executor interface {
    Authorize(ctx context.Context, query *CompiledQuery, principal invocation.Principal) (*Authorized, error)
    Open(ctx context.Context, authorized *Authorized) (Execution, error)
}
func (a *Authorized) ShareKey() string
type Execution interface {
    Current(ctx context.Context) (Window, error)
    Changes() <-chan struct{}
    Done() <-chan error
    Refresh(ctx context.Context) error
    Close() error
}
```

`CompiledQuery` is opaque and immutable. Compilation validates request, declarations, bindings, profile and host-resolved catalog/access metadata; it holds no mutable source snapshot. The host resource controller implements `SourceBinder` and `CatalogSource` through catalog admission and the admitted route's P07 catalog snapshot, under the P12 live-integration controller lock. `Authorize` independently authorizes `invocation.Principal`, resolves bindings and epochs, and returns opaque `Authorized`; possession of a compiled query grants no access. AccessEpoch is canonical host text of catalog admission's `{PluginID, Generation, Connection, Epoch}`, not a principal or client assertion. `Open` rechecks authorization epochs and returns `RESET_REQUIRED` or the applicable C02 access error after changes; it admits cost and acquires only necessary interests. It establishes observation atomically and releases all interests on failure.

`Authorized.ShareKey()` returns a host-computed digest over the host-derived principal owner, compilation identity, canonical binding values, effective targets, scopes and representations, order, projection, delivery and access epochs. Different owners never share; tabs with the same admitted TrustedUI window owner may share when all other fields match. Never log raw values. P14 shares only after authorization and matching keys; neither client nor provider supplies authority or the hash.

`Window` is an immutable host value: ordered `Rows []Row`; per-target P12 `Coverage` including state, consistency, continuity and limitations, `Freshness`, `Watermark`, and source epoch/attempt; `Count resourcev2.Count`; optional host `Continuation`; and departed keys with cause `sourceMembershipRemoved`, `noLongerMatches`, or `outOfWindow`. A row includes target, canonical reference, compact `resourcev2.RepresentationRef` (`id`, `revision`, optional `schemaRevision`), source provenance, P01 projected absent/null/value states and P12 `Stale`. Its representation ref matches the admitted C04 binding; inline schema bytes are not carried per row. Stale rows appear only under explicit `allowPartial`, with target coverage marked partial; otherwise exclude them, never promote them to current. P12 `Snapshot.Changed` supplies touched membership needed to distinguish removal from filtering or window movement. Counts are exact only when proven. Watermarks are P12 host watermarks, never source revisions or P14 generations. C08 owns result wire semantics.

`Changes` is a stable channel with at most one coalesced pending invalidation. Subscribe before the first `Current`; a concurrent change is either included in that coherent window or remains pending. `Current` returns the latest immutable window or terminal error under the execution lock; it is also the initial attachment. `Done` is a separate buffered terminal lane yielding one error or nil on normal completion. There is no P13 data queue or result-overflow-triggered source reopen. P14 recovery is make-before-break so interests never reach zero solely due to result overflow. `Refresh` delegates to acquired interests. `Close` is idempotent, cancels work and releases interests without waiting on a consumer. `once` completes after its initial image; `follow` requires a supported bounded window and real update capability, otherwise `UNSUPPORTED`. P14 owns result diffing, generations, sequence, queues, batching and terminal control. Source and result generations remain independent.

The host resource controller implements `SourceBinder` through catalog admission and route epoch; P12 live integration owns that controller lock. It calls `readmodel.NewBinding` with admitted selection and access epoch. Invalid, denied and unsupported binding map to C02 `INVALID_REQUEST`, `FORBIDDEN` and `UNSUPPORTED`. P12 `Snapshot.Err` maps `ErrDenied` to terminal `FORBIDDEN`, `ErrUnsupported` to `UNSUPPORTED`, `ErrLimit` to `RESOURCE_LIMIT`, `ErrUnavailable` to `UNAVAILABLE`, and `ErrResetRequired` to `RESET_REQUIRED` or a source reset indicated by target epoch/attempt. Derive departed-key causes from P12 changes: removed or retired means source membership removed; a still-current row failing residual means no longer matches; a paged-out row means out of window. A staled row is an update when partial is allowed; otherwise it leaves as no longer matches. P14 decides the wire transition.

## Compilation and admission

1. Strictly decode and bound P01 `QuerySpec`; normalize explicit targets/scopes, identifiers, typed declarations and values. Targets remain distinct union memberships. Reject duplicates, unknown fields, invalid scopes and missing/extra/reserved bindings. Bind values as native CEL activations, never source interpolation. Lower Builder v1 to the accepted CEL grammar, preserving lexical array-element correlation and guard/negation semantics; use the same evaluator as text CEL.
2. Resolve each host-authorized target, effective route, representation, catalog snapshot and capability before checking. Resolve P07 `Snapshot.Entry` and `Entry.Resolve`; unavailable schema is an error, absent schema is bounded dynamic admission. Obtain `celtypes.NewEnvironment(snapshot.Revision(), entry, schema)` and key checking by its `Revision`, not `ContentKey`. No schema existence implies query or native execution authority.
3. Parse, resolve and check against the selected P01 environment. Known non-Boolean result rejects; `dyn` must evaluate to actual Boolean. Compile checked native CEL with pinned profile and immutable environment. Compilation identity includes normalized source/profile, declaration types, environment and schema revisions and implementation revision, not binding values. Runtime sharing identity additionally includes values and effective access/target/window context; do not log sensitive values.
4. For each candidate row, validate through P07 `resourcecatalog.Admit(ctx, schema, value, coverage, policy)` and `celtypes.ToCEL`; honor its validation capability and unvalidated constraints. Admission and required field coverage, acquisition and authorization resolve independently before CEL, text, ordering and projection. Permission denial cannot become partial success. Unavailable is never absent, null, default or false; hydrate only by a supported admitted plan, otherwise reject or return explicitly permitted partial coverage. CEL Boolean/error masking must never suppress those failures.

The profile uses native standard operators and `has`, `all`, `exists`, `exists_one`, `map`, `filter`, with no host callbacks, I/O, extensions, alternate equality or custom numeric engine. Preserve exact tagged int64/uint64, finite double, timestamps, lists and maps. Static mixed equality remains a checker error; dynamic mixed comparisons and optimized membership use the pinned fork. Explicit numeric conversions can be lossy. Correlated predicates over one array element use one lexical binding; separate existential tests are not equivalent. P01 text ANY, missing/null and conditional union rules remain normative.

## Planning and finite result

Select local, native or hybrid per target from authorized capability, scope, schema/representation and bounded available work. This packet does no CEL-to-native predicate pushdown: P45 `NativeQueryDescriptor` declares only a language and input schema, not semantic equivalence or filtering capability. Local is the default. Native acquisition is an explicit admitted P01 native-query target through C04 `NativeQueryAcquisition`; hybrid applies the full host residual to those native candidates. A native request must itself establish a candidate superset for the effective query; otherwise reject `UNSUPPORTED`. Future CEL pushdown requires a separately reviewed additive SDK semantic descriptor and pinned adapter, not inferred provider behavior.

Preserve the complete original predicate as residual and every field it requires. Native page size bounds transport, not final host cardinality. Native projection, limit, ordering or cursor must not discard rows or fields needed for residual, global sorting or projection. Continue all necessary source pages within explicit acquisition/time/byte/item budgets; never silently crawl broader scopes, treat the first source page as a result, or truncate exact output. Native-only sources reject unsupported subsets; no-native sources use bounded local execution when possible. Partial/unknown source replacement and stale P12 rows retain provenance; they never prove deletion or exact membership.

After full admitted scope, text and predicate/residual membership, apply P01 global order including missing/null placement and canonical target/address/incarnation tie-break, then projection and final page. Source order and revision are not result order or recency. Host opaque continuation binds effective query/order/profile, bindings, schema/access, result generation, consistency and expiry; it is never a source cursor. Invalid or expired continuation returns `CONTINUATION_EXPIRED` or `RESET_REQUIRED`. Count is unknown unless exactness is actually established. `allowPartial` defaults false; true permits only policy-authorized partial results carrying explicit coverage and limitations, never forbidden acquisition.

## P12 integration and lifecycle

P12 `readmodel.Manager.Acquire(ctx, Binding, InterestKind) (Interest, error)` yields independently refcounted interests; `Interest.View`, `Refresh`, and `Close` own their source lifecycle. Snapshots expose `Revision`, `Coverage`, `Freshness`, `Get`, `Changed`, `Err` and `Range`; `Changed` emits upsert, staled, removed and retired causes. Bindings include exact source selection, representation and access epoch. A view is one bounded consistent published revision; callback rows cannot be retained as mutable references. Copy only projected data needed after the callback. Range errors, stale rows, provenance and cancellation remain explicit.

Obtain `Interest.Changes()` before the first `View`, then re-view after every coalesced notification. A concurrent change is reflected in the coherent view or remains pending. `InvalidateEpoch` revoked yields `ErrDenied` and terminal `FORBIDDEN` on `Done` (C08 access invalidation); transitioned yields `ErrResetRequired` and terminal `RESET_REQUIRED`. P14 must authorize again under the new epoch; an execution never rebinds itself. Source refresh and generation retirement cannot overwrite newer work.

C04's revised candidate carries the P45 record `Coverage` unchanged, separately from typed `knownAbsent`; pass the former to C05 `Admit` without coercion and preserve the latter for evaluation. Do not reject a row merely because it is partial. P12 enumeration coverage remains independent. Never map `knownAbsent` to limitation paths.

After `Admit`, if an `UnavailablePaths` entry equals a typed `knownAbsent` path, return `UNSUPPORTED` for that row: the admission result cannot distinguish union-branch failure from body failure. Other unavailable paths go through coverage policy: hydrate, explicitly allow partial, or reject. Before CEL, inspect all attribute paths referenced by the checked AST. A present field yields its value. Under partial or unknown coverage, a missing path is unknown only at or below a segment-wise RFC6901 limitation path, or everywhere when `Paths` is empty; otherwise absence is known. `knownAbsent` remains known absent even inside a limitation subtree, so `has()` is false. A subtree referenced by comprehension (`all`, `exists`, `exists_one`, `map`, `filter`), `in`, dynamic index, size, equality or whole-value comparison is indeterminate if it is an ancestor of, equal to, or inside a limitation path: hydrate, allow partial, or reject. For example `resource.metadata.exists(k, k == "managedFields")` must not evaluate false merely because that subtree is limited. Acquisition, admission and access errors remain independent of Boolean masking.

C04's proposed `SourceObservation.document` is a tagged P45 `resourcev2.Value` map, passed directly to C05 admission and `celtypes.ToCEL`, preserving numeric and timestamp intent. This is an unapproved C04 revision, not a claim the prior raw JSON contract was already typed; implementation requires explicit C04 user approval. No JSON-to-Value decoder or schema-based timestamp inference is used on this path. C05 omission-sensitive collection and union constraints report indeterminate `UnavailablePaths`, while definite present violations remain invalid.

Host policy bounds source, decoded document and output bytes, nodes/depth, parse work, acquisitions, candidate/evaluated rows, concurrent operations, runtime CEL cost, memory and deadline. Apply P01 policy limits and P07 catalog policy at their owners; hosts may lower, not silently raise them. P01 reference limits are not a claim of production measurements. `RESOURCE_LIMIT` reports exhausted work, `INVALID_REQUEST` malformed/type/non-Boolean input, `UNSUPPORTED` unavailable semantics, C02 access/source errors preserve safe codes, `CANCELLED` and `TIMEOUT` represent actual lifecycle termination. Cancellation is checked before admission, during source paging and native `ContextEval`, before output, and propagates to all acquired work. No failed or cancelled result is emitted as success.

## Independent behavior PRs and gates

- Compiler owner: real parse/resolve/check/compile, canonical typed bindings, P07 admission and bounded profile, with direct exercised behavior and tests; no fake planner or evaluator.
- Planner owner: capability-qualified native/local/hybrid acquisition and residual preservation, integrating the reviewed compiler and P12 candidate. Any SDK capability extension has its own reviewed additive PR and exact candidate pin.
- Finite execution owner: real admitted execution, global order/window/host cursors and lifecycle integration against pinned prior candidates. C08 integrates only after P13 interface review and C08 user approval; no placeholder follow stream.

These are ownership locks, not permission to implement before reviewer-approved P12/P13 interfaces and user-approved C05. Each behavior PR must have real useful behavior, tests and an executable smoke, independent review before expensive CI, exact reviewed candidate revisions, and no shims. The integration owner coordinates shared files and rebases after predecessor merges. Final packet acceptance still requires merged predecessors, required CI and live evidence.

Review must challenge candidate-superset proofs, masking/coverage ordering, cross-epoch access isolation, P12 observation atomicity, bounded stalled-consumer termination, exact numeric/correlation behavior, global paging across source pages and stale-row treatment. Required acceptance includes the independent P44 matrix and actual source→admission→CEL→window integration, cancellation, partial/denial and 300/3000/30000 acquired/evaluated/delivered work and memory measurements. No such verification is claimed by this specification.
