# First-cycle analysis

## Observed skill effect

The paired decision cases passed 18/18 assertions with the skill and 13/18 without it, after a baseline-favorable adjudication. One sample per case does not establish statistical reliability. The viewer's per-case mean is distinct from this assertion-weighted total.

The useful discrimination was not generic refusal to finish without screenshots: both variants already blocked stale/missing evidence and accepted valid near-misses. The skill improved specific boundaries: resource identity versus series dimensions; shared density and spacing ownership; rejection of local trigger-CSS substitutes; and recognition that an approved Input wrapper still exposes browser-native temporal interaction.

Case 1's switcher assertion was initially overstrict about installed API sufficiency. The baseline correctly demanded restoration or approval. Its grade was corrected in its favor; original independent grading remains available. Future cases should supply an explicit API inventory when asserting an API exists.

## Enforcement iteration

Independent code review exposed and drove fixes for resumed-session baseline resets, selected sibling source layouts, finding-identity subtraction, approved-exception handling, mutable React factory aliases, and temporal object spreads. Clean-checkout CI needed a merge-base comparison rather than a HEAD-only working-tree diff.

Actual OMP execution caught a dependency-resolution failure that Node tests did not expose. The hook now runs the syntax parser through a Node worker and registers completion blocking before dependency initialization. The runtime smoke also had to observe stop attempts before the refusing handler, because later stop callbacks do not run after a refusal. These are separate production-integration and test-observer fixes, not evidence that application rendering was tested.

## Evidence limits

- Text evaluations have no tools, execution, visual input, or actual browser proof.
- Metadata-only trigger cases matched 4/4 expected decisions; actual CLI discovery is separately recorded.
- Deterministic tests exercise approval and rejection transitions, baselines, selected repositories, paths, and syntax rules.
- The actual CLI smoke exercises parent rejection, completion refusal and continuation, and an actual high-effort independent child's unverified report. It intentionally has no app or pixel baseline, so independent approval must remain false.
- Production/native visual acceptance and human review of the skill outputs remain separate. Never convert these guardrail results into a claim that the metrics regressions are fixed.
